## 验证边界

真实提供方检查使用短合成素材，不代表任意长视频、所有模型或所有中转站都支持相同输入。大文件 Files API、500k 真实长会话、角色关系长期演变仍需在日常使用中验证。500k 是目标容量，Token 计数是保守估算；界面端到端检查采用明确标注的演示模型，桌面宿主服务和模型通道另行使用真实运行时验证。

正式档案没有预写测试聊天，也没有擅自替用户指定默认模型。第一次打开沙龙，选择已有 DSH 模型即可开始。
