# 四季沙龙

这是 DSH 的独立 dual-face 陪伴插件，不是 Sites 网站。用户以娱乐、拟人角色互动为核心，token 充足，不要擅自用小上下文或低价模型替换用户选择。

## 已确认产品要求

- 四名预置成年女性角色：听话女仆、不耐烦女仆、腹黑千金、色气神秘大姐姐；人设可编辑，可添加成员。百合群像与用户参与均可，不预设用户性别。
- 群聊与每位角色的一对一私聊。个人记忆独立，私聊记忆、摘要、日记不能进入公开群聊或其他角色的上下文。
- 角色平时可主动聊天，不依赖用户上传新视频。
- 群聊持续进行，由成员自己判断何时没有补充并自然结束，不设固定接话轮数；一人沉默不能结束整群，用户随时可插话/停止。
- `@` 成员补全、`@全体`、成员之间互相点名与优先回应。讨论中点名应被处理，不能要求用户先停止聊天。
- 按正常群聊直接说话，不要括号动作、心理活动或旁白；流式显示和最终消息都过滤中英文括号内容。
- 用户手动导入本地抖音等视频，不做平台抓取、登录或联网刷视频。
- 必须同时保留真实视频直传和抽帧配声音材料两条通道。不得把抽帧标成直传；默认不得在直传失败后静默回退。
- 目标上下文 500,000 tokens，按模型公开容量取较小值；token 数是保守估算，不能声称精确计数。保留最近原文，旧对话接近预算才摘要，原文不删除。
- 长期记忆参考 SillyTavern 的角色卡、lorebook 和摘要机制：核心人设常驻、置顶记忆、中文关键词相关性召回、来源消息、可编辑和回退的增量摘要。当前未接 embedding，不要声称向量检索。

## 工程

- `src/`：Node ESM，host 服务、持久化、角色引擎、上下文与视频通道。
- `client/`：React UI；构建为 DSH ModuleLoader 闭包，React 使用宿主共享实例。
- `shared/chat.mjs`：host/client 共享的点名识别、补全查询和聊天内容清理，打包时保留在包根目录。
- `lib/`：构建产物，`npm run build` 生成，不手改。
- `scripts/dev.mjs --demo`：明确标记的演示模式；与真实 `.dsh/storages/dsh-salon` 数据隔离。
- `tests/`：有意义的隔离、持久化、停止、摘要、视频字节与真实 FFmpeg 检查。
- `npm test`、`npm run build`、`npm run check`；界面检查 `npm run test:ui` 会自动启动隔离的演示服务。
- 真正的 DSH 运行时检查使用本机安装的 Electron，以 `ELECTRON_RUN_AS_NODE=1` 运行 `tests/host-contract.cjs`。真实 API 检查 `tests/live-provider.cjs` 会消费少量模型额度，只传合成测试素材。

## 数据与凭据

正式数据位于 `$DSH_HOME/storages/dsh-salon`，不在仓库。`state.json` 原子替换，上一版在 `state.json.bak`。拒绝读取损坏状态，不静默重置。视频文件和抽帧在 `media/<UUID>/`。

模型与凭据复用 DSH 的 `llm`、`settings`、`credentials`、`attachments` 服务。网页只接收凭据变量名，不接收真实密钥。不输出用户凭据，也不把配置和密钥复制进仓库。

## 修改约定

不要重写 DSH 源码，也不要覆盖现有插件和宿主配置。桌面插件安装使用 `scripts/install.ps1`，内部走已安装 DSH NEXT 的官方插件管理器。未经用户要求不重启正在运行的桌面程序。

实现变化同步更新 README 和 docs/ARCHITECTURE.md。优先验证实际行为，模拟测试不能替代真实提供方与宿主兼容性说明。
