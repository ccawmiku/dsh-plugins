## 实际 Web 界面

使用独立 `DSH_HOME`，通过官方 `dsh plugin --profile web add` 安装本插件，再启动官方 Web profile。没有向用户正在运行的桌面 profile 安装插件，也没有改变用户已有模型配置。

- 插件列表显示中文标题“视频输入”、描述和启用开关。
- 原有“文件”入口保留，“添加视频”入口出现在加号菜单。
- 从菜单选择两个 MP4，文件选择器声明支持多选；原生附件卡显示上传中，随后显示文件名与大小。
- 上传后仍停留在草稿区，没有自动发送；可继续编辑文字。
- 单独移除一个视频后，另一个附件与文字保留。
- 从 `.tgz` 安装后，组件详情出现“配置 视频输入”入口；全部参数可编辑，修改视频数量上限并保存成功，然后恢复默认值。
- 中英文插件标题、描述和配置标签显示正确；深色与浅色主题均已目视核对，随后恢复中文与原主题。
- 截图见 [web-menu.jpg](web-menu.jpg)。截图是隔离环境的未发送草稿；该环境未配置模型。真实模型端到端测试由上面的 Agent Loop 测试完成。

## 限制

没有自动操作或重启用户正在运行的 DSH NEXT 桌面端。桌面与 Web 共用本插件的浏览器模块，桌面文件走强制上传路径的代码已核查；原生 Electron 文件选择器仍需在用户实际安装后核验。`0.2.1-rc.2` 的兼容声明基于已核查 API，完整运行验证基线为 `rc.3`。

仅用 6 秒合成 MP4 验证，不据此承诺长视频、所有编解码格式或所有 OpenAI 兼容网关均可直传。当前网关的 Responses 视频内容丢失问题已经在接口调查中确认，因此插件仅在 Chat Completions 路径使用直传。

测试视频由纯色、数字和本机语音合成生成，不包含用户私人视频。测试凭据仅进入测试进程的环境和内存，未写入仓库、安装包或测试输出。
